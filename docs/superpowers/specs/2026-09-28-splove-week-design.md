# СПLOVE: день сплава, бустеры, бонусы недели (шаг 2 сезона)

Дата: 2026-09-28. Продолжает `2026-09-28-splove-season-design.md`. Решения взяты из разговора с Виктором: раз в неделю новая трасса, бустеры на следующие заплывы, сезонные баллы, посты в чат не чаще раза в неделю и **выключены, пока Виктор не скажет**.

## Договорённости

- **Заплыв недели:** у всех игроков на неделю одна и та же трасса, сложность «Сплав». Попыток сколько угодно. Неделя ISO по Москве, как у заданий.
- **Зерно трассы** одно на неделю: `weekSeed = Math.imul(weekIndex + 1000, 0x9E3779B1) >>> 0`. Форма реки зависит от ширины экрана, поэтому на разных телефонах трасса похожа, но не совпадает пиксель в пиксель. Это принято.
- **Таблица недели** — отдельная: лучший банк игрока за неделю, при равенстве выше тот, кто набрал раньше. Топ-10 и место игрока.
- **Заплывы недели не попадают** в таблицы по сложностям (`bests`), но идут в задания и статистику.
- **Баллы** (`points`, ключи идемпотентны): за участие +50 (первый заплыв недели), бонус места по итогам недели 1-е +300, 2-е +200, 3-е +100. Числа лежат в одном объекте `WEEK_POINTS`.
- **Бонус места** начисляет расписание (cron) в ночь на понедельник 00:05 по Москве за закончившуюся неделю; повторный запуск ничего не удваивает. Забаненные в бонусе не участвуют. Сезон недели, которая делится между сезонами (W53), определяется по её последней секунде.
- **Бустеры:** за первый заплыв недели выдаётся один бустер случайного вида (случайность детерминирована от игрока и недели, повтор запроса даёт тот же). Виды:
  - щит: первый удар за заплыв не отнимает ни весло, ни очки;
  - удвоение: очки за метры, бутылки и борщ ×2 до первого лагеря (уха Санчеза и запасное весло не удваиваются);
  - запасное возвращение: +1 возвращение в лагерь.
- **Использование:** на главном экране плашка с бустерами; нажатие «заряжает» один на следующий заплыв. При старте клиент вызывает `POST /api/booster/use`, сервер списывает бустер атомарно; ошибка или отсутствие означает игру без бустера. Эффект считает клиент (как и всё остальное в заплыве), поэтому подделать его можно; призёров проверяют руками.
- **Итог недели в чат:** переменная `WEEKLY_POST` (`off` по умолчанию, `on` включает). При `on` после начисления бонусов бот шлёт **одно** сообщение в активные чаты: топ-3 недели и топ-3 сезона. При `off` не отправляется ничего.

## Данные

Миграция `0008_week.sql`:

```sql
ALTER TABLE runs ADD COLUMN mode TEXT NOT NULL DEFAULT 'free';   -- 'free' | 'week'
ALTER TABLE runs ADD COLUMN week TEXT;                           -- '2026-W41' для заплывов недели
CREATE INDEX idx_runs_week ON runs (mode, week, tg_id);

CREATE TABLE boosters (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  tg_id INTEGER NOT NULL,
  kind TEXT NOT NULL CHECK (kind IN ('shield','x2','life')),
  earned_key TEXT NOT NULL,                                       -- 'b:2026-W41'
  earned_at INTEGER NOT NULL,
  used_at INTEGER,
  UNIQUE (tg_id, earned_key)
);
```

Внешних ключей на `players` нет (как у `points` и `visits`).

## Сервер

- `POST /api/runs` принимает необязательные `mode: 'week'` и `week`. `week` обязан совпадать с ключом текущей недели, иначе заплыв записывается как обычный. Заплыв недели не обновляет `bests`. Принятый (не отклонённый) заплыв недели: `+50` за участие (ключ `w:<сезон>:<неделя>:play`) и выдача бустера недели, если ещё не выдан (`b:<неделя>`).
- `POST /api/week`: `{ weekKey, seed, level: 'normal', endsAt, board, me, boosters, granted }`. Таблица недели по `runs WHERE mode='week' AND week=?` (принятые, забаненные скрыты), лучший банк на игрока. Тот же `recordVisit`.
- `POST /api/booster/use { kind }`: списывает самый старый неиспользованный бустер этого вида, атомарно (`UPDATE ... WHERE id = (SELECT ...) AND used_at IS NULL RETURNING`). Нет бустера: `409 no_booster`.
- Расписание: `[triggers] crons = ["5 21 * * 0"]` (воскресенье 21:05 UTC = понедельник 00:05 МСК). Обработчик `scheduled` вызывает `closeWeek(now)`: находит неделю, закончившуюся до `now`, начисляет бонусы мест, при `WEEKLY_POST = 'on'` шлёт итог.

## Клиент

- На главном экране кнопка «Заплыв недели» (видна в Telegram при идущем сезоне) со строкой «неделя W41 · до конца 3д 04:10».
- Старт заплыва недели: сложность «Сплав», `reset(weekSeed)`, заплыв уходит с `mode:'week'`. Итоговый экран показывает место в таблице недели.
- Экран «Сезон» дополняется таблицей недели.
- Бустеры: плашка над кнопками, нажатие включает/выключает выбранный; при старте `POST /api/booster/use`; эффект применяется в `start()`.

## Проверка

- Тесты воркера: зерно недели стабильно и разное по неделям; бонус недели идемпотентен; забаненный не получает бонус; неделя на стыке сезонов; выдача бустера один раз за неделю и детерминирована; `use` атомарен (гонка двух запросов списывает один раз); заплыв недели не меняет `bests`; `WEEKLY_POST=off` ничего не шлёт, `on` шлёт один раз.
- Игра (Node-харнесс): щит гасит один удар, удвоение действует до первого лагеря, запасное возвращение прибавляет попытку, нулевая ступень без бустеров не меняется (эталон `golden-stage0.json`).
- Клиентские тесты отрисовки таблицы недели и плашки бустеров.

## Не делаем

- Отдельная сложность или ограничение по времени недельной трассы: это этап «Шторм».
- Проверка заплывов на сервере.
- Автоматическая выдача призов.
