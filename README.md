# СПLOVE — игра

Сплав по Волге на трёхместной байдарке. Авторская игра @sorval.

**Играть: https://sorvalliny.github.io/splove-game/**

Управление с телефона: палец слева или справа — рулить, два пальца — рывок.
Удар стоит весла, лагерь сохраняет очки. Пиво, вино и текила дают очки и хмель.

Три уровня: Прогулка, Сплав, Шторм.

## Как устроено

Один файл `index.html`, без зависимостей и сборки. Графика на Canvas,
музыка и звук синтезируются через WebAudio. Хостинг — GitHub Pages.
